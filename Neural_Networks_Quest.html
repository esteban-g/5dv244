How to use this in class

Do not treat this as a race. Before changing a parameter, predict what will happen. Then change it, observe the real calculation, and explain why. The four core missions deliberately build the same chain used in the lecture:

neuron → network → loss → gradient descent → backpropagation → deep learning

Progress is stored locally in this browser. No student identity is collected. Use “Export results” at the end if you want a local JSON file.

Built as a pedagogical companion to Lecture 6. The calculations are implemented directly in JavaScript; the companion Jupyter notebook verifies the key operations with NumPy and PyTorch autograd.

Agent Academy briefing

Different agent architectures are appropriate for different decision-making problems.

Simple reflex agents use the current percept and condition–action rules.
Model-based agents maintain information about the world beyond the current percept.
Goal-based agents use goals to select actions that eventually lead to desirable states.
Utility-based agents can compare alternatives according to how desirable their outcomes are.
Learning agents can improve their behavior through experience.

🧠 Agent Academy Briefing

A BDI-style cognitive agent can be understood through a sequence of related components:

Beliefs represent the agent's information about the world.

Desires represent objectives or possible goals that the agent would like to achieve.

Intentions represent what the agent commits to pursuing.

The agent can then construct a plan and execute the selected actions.

The important idea is that the agent is not merely reacting to an immediate percept. It maintains internal cognitive representations that influence its decisions.

🔎 Challenge 4 — Query the knowledge base

Knowledge representation is useful because we can Ask the knowledge base questions.

The lecture demonstrates this using Description Logic queries in Protégé. For example, the People ontology can be queried using class expressions such as:

adult and has_pet min 1

What kind of question does this query represent?

Find all adults.
Find adults that have at least one pet.
Find all pets that are adults.
Find people that have no pets.

Mission 1: Data Detective

Machine learning starts with a surprisingly important question: What kind of problem are we trying to solve? Before choosing an algorithm, you need to understand the data, the target, and whether the answers are already known.

🔬 First stop: The Learning Lab

Imagine that you are designing a machine learning system. The first thing you must determine is whether the training data contains known answers.

Scenario A — The Spam Detector

You have thousands of emails. Each email has already been labelled as either spam or not spam.

Email → [features] → "spam" / "not spam"

Does the dataset contain a target value?

Scenario B — Discovering Customer Groups

You have information about 10,000 customers, but nobody has labelled the customers into groups.

Customer → [age, spending, visits, ...]

You want the algorithm to discover possible groups in the data.

🎯 Target Detective

Now suppose that the problem is supervised. Your next question is:

Is the target numerical or categorical?

Remember the distinction from the lecture: regression predicts numerical targets, while classification predicts categorical targets.

Scenario C — Predicting House Prices

Input: house size, number of rooms, location, age...

Target y = €350,000

What kind of supervised learning problem is this?

Scenario D — Detecting a Disease

A model receives medical measurements and predicts:

Target y ∈ {disease, no disease}

What kind of supervised learning problem is this?

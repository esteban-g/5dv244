🎓 Mission Complete

A classifier does not simply produce a class label. In the logistic model explored here, the model first produces a numerical score, which the sigmoid transforms into a probability. A decision rule can then use a threshold to convert that probability into a class.

This distinction becomes important when we evaluate models: changing the threshold can change the decisions even when the underlying model and probabilities remain unchanged.

Think about this: If the cost of a false positive and a false negative were very different, would 0.5 necessarily be the best threshold?

🧠 One dataset, different representations

Imagine that every observation in a dataset is described by several features.

Original representation

An observation might be represented by many variables:

x = (x₁, x₂, x₃, ..., xₙ)

This representation can contain useful information, but it can also be difficult to visualize and process.

Reduced representation

A dimensionality-reduction method tries to represent the observations using fewer variables:

z = (z₁, z₂, ..., zₖ)

The goal is to preserve important structure while using fewer dimensions.

The Logic Gate

Declarative reasoning begins here
Before an agent can reason about the world, we need to understand how the problem is described.

In this mission you will distinguish between procedural and declarative approaches — and take your first step into Answer Set Programming (ASP).

Challenge 1 — How should we describe the problem?

Imagine you want to create an intelligent agent that determines whether an animal can fly. Which approach is declarative?
A. Write a sequence of instructions telling the agent exactly how to determine whether an animal flies.
B. Describe facts and rules about animals and let a reasoning mechanism determine the consequences.
C. Write a loop that checks every animal and manually calculates the result.

Challenge 2 — Find the facts

Consider this small ASP-style knowledge base:
bird(tux).
bird(eddy).
penguin(eddy).
Which statements are explicitly represented as facts?
A. bird(tux), bird(eddy), and penguin(eddy)
B. Only bird(tux)
C. Whether Tux can fly

Challenge 3 — What does the rule say?

Now suppose the knowledge base contains the rule:
flies(X) :- bird(X), not penguin(X).
What is the main idea expressed by this rule?
A. Every bird is a penguin.
B. An entity can be concluded to fly when it is a bird and it is not known to be a penguin.
C. Every penguin must fly.

Key idea to remember:

In a procedural approach, the designer specifies how the computation should be performed.

In a declarative approach, the designer describes what is known or required and leaves the reasoning mechanism to determine the consequences.

In ASP, problems are described using facts and rules, while solutions are represented as answer sets.

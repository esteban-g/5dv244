Mission 3: Reasoning with interconnected uncertainty

You have learned how Bayes' rule allows an intelligent agent to update a belief when new evidence arrives.

But real-world reasoning rarely involves only two variables.

Several uncertain events may influence one another.

Your mission is to investigate a Bayesian network and use it to answer questions about an uncertain world.

🧠 Investigation 2 — Conditional independence

One of the main advantages of a Bayesian network is that it makes some independence assumptions explicit.

Consider John calls.

If we already know whether the alarm is sounding, does knowing about the burglary directly add information about John's call?

Which statement best describes the idea?

Detective clue:
  • Bayesian networks encode a joint probability distribution.
  • The graph structure represents conditional dependencies and independencies.
  • Inference combines the network structure with probability information.

🔎 Investigation 3 — Find the hidden cause

Now imagine that you do not know whether a burglary occurred.

But you observe:

  • 🚨 The alarm went off.
  • 📞 John called.

The interesting question becomes:

P(Burglary | Alarm, John calls)

This is exactly the kind of inference question that a Bayesian network allows us to investigate.

🧩 Detective's Reflection

A Bayesian network does not merely store isolated probabilities.

It provides a structured representation of how uncertain variables are related.

This allows an intelligent agent to answer questions such as:

  • What is the probability of a hidden cause?
  • How does new evidence change that probability?
  • Which variables become conditionally independent when other information is known?

Final question

Why is the network structure useful rather than simply listing one enormous joint probability table?

🧠 Challenge 1 — Probability is not enough

Imagine an industrial system that may fail.

An intelligent agent estimates:

P(Failure | Evidence) = 0.30

The agent now has two possible actions:

  • 🔧 Repair the system now.
  • ⏳ Do nothing and continue operating.

Is the probability of failure alone enough to decide?

What else does the agent need?

⚖️ Challenge 2 — Actions have consequences

Decision theory combines uncertainty about the world with preferences over possible outcomes.

Consider the following decision structure:

🔧 Repair
→
😊 Avoid failure

⏳ Do nothing
→
⚠️ Possible failure

But the world itself is uncertain.

The system may fail or it may not.

What does expected utility allow the agent to do?

📐 Challenge 3 — Maximum Expected Utility

The expected utility of an action is calculated by weighting the utility of each possible outcome by its probability.

EU(a) = Σ P(s | e) × U(a,s)

A rational agent chooses the action with the highest expected utility.

Suppose:

Action A has expected utility 72.

Action B has expected utility 54.

Which action does the MEU agent choose?

🧩 Final Reflection — What makes an agent rational?

Throughout this quest you have encountered several different forms of reasoning.

  • Probability represents uncertainty.
  • Bayes' rule updates beliefs using evidence.
  • Bayesian networks represent structured probabilistic dependencies.
  • Causal reasoning allows agents to reason about interventions.
  • Decision theory connects uncertainty with action.
Beliefs + Preferences → Rational Action
